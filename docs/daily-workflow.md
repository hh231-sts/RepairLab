# 日常使用：界面创建工单并运行

每张新工单不需要重新配置 API Key、重建数据库或复制 PowerShell 请求。项目、仓库版本、依赖环境和验收器准备好后，日常操作在浏览器完成。

## 一次配置和每次启动

真实模型 Key 和价格快照保存在项目根目录 `.env`。前端连接设置中的 API_TOKEN 是本地接口认证凭据，不是 DeepSeek API Key。密钥不会返回给浏览器。

在第一次切换到新版启动方式前，用 Ctrl+C 停止此前手动启动的 API、worker、前端终端。之后可用项目启动/停止脚本统一管理：

```powershell
# 开启真实模型模式。默认不带此参数时，仍关闭真实模型。
.\scripts\start.ps1 -EnableModelCalls -SkipImageBuild

# 依赖已安装、只需快速启动时：
.\scripts\start.ps1 -EnableModelCalls -SkipImageBuild -SkipSetup

# 停止本项目管理的进程；保留数据库、工单和产物
.\scripts\stop.ps1
```

首次没有镜像时省略 `-SkipImageBuild`；首次没有依赖时省略 `-SkipSetup`。启动时只检查本地配置完整性，不调用模型做连通性探测。embedding 继续关闭。Linux/WSL 使用 `bash scripts/start.sh --enable-model-calls`。

打开 http://localhost:5173。顶部状态从真实后端读取，区分模型关闭、配置未就绪和已启用。配置不完整时不能从页面发起真实调用。

## 每张工单

1. 进入“工单管理”，点击“新建工单”。
2. 选择已有项目。相同仓库版本、相同验收条件可以选择同项目的“执行环境与验收模板”，自动带入镜像、修改范围、公开测试和验证器版本。
3. 填写标题、问题描述和验收条件，设置工单预算后保存。新的问题需要对应的独立验证测试，不能把旧问题的测试当成通用答案判定器。
4. 点击工单的“发起运行”，选择“DeepSeek 真实模型”和执行策略。
5. 设置本次运行的费用、调用次数和执行期限。默认 1 元、20 次、600 秒；只能降低工单契约的限制，父子 Agent 共用预算。
6. 点击“发起真实模型运行”，在运行详情查看状态、Agent 关系、工具、补丁和独立验收结果。失败可直接点击“新建重试”，保留原始记录和本次预算设置。

“工具与证据”页面新增模型调用与计费记录，显示 usage、费用预占、结算和安全错误详情，不再需要用命令查询这些字段。费用按配置的价格快照估算，厂商最终计费以账户账单为准。

## 现有 clamp 夹具

可直接在已有工单上发起新运行，也可以新建同项目工单并复用该验收模板。夹具解决的是倒置边界应抛出 ValueError 的问题，用于验证真实模型调用和平台链路，不是正式 SWE-bench 成绩。

## 新仓库的首次准备

需要先登记固定 commit、准备可运行的 Docker 依赖环境和可信独立验证器。已有 Harbor/离线任务包通过管理员导入流程接入；具体见 [任务说明](tasks.md)。这些是新项目的环境接入工作，不是每次填写工单都要重复执行的步骤。
