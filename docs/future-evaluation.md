# 后续真实模型验证计划

本轮完成工程实现与无真实模型的验证。以下均为待执行工作，不计为已交付数据或效果：真实 DeepSeek 连通性与多轮工具实测、E5 权重加载与检索质量评估、36 个真实任务入库、108 次正式实验、模型能力与协作收益报告。

## 启用前

人工核对 DeepSeek 官方当前模型与价格，保存模型 ID、参数和价格快照；设置实际 input/output 单价。示例配置的价格为 0 且快照为 unconfigured，代码会拒绝付费调用。启动脚本默认关闭真实调用，使用 `-EnableModelCalls`（Windows）或 `--enable-model-calls`（WSL/Linux）显式启用。前端或任务参数不能开启服务器模型开关。单次真实试跑见[日常操作](daily-workflow.md)，与正式 benchmark 实验分开记录。

E5 固定 revision 已记录。后续另行安装 optional embedding 依赖，并在受控步骤准备该 revision 的本地模型缓存；Adapter 使用 local_files_only，不会在任务中下载。模型、重排和 Judge 的资源消耗均需纳入正式预算，不用隐藏辅助调用改变实验成本。

## 数据与实验

按任务文档导入、预检和冻结 pytest/sphinx/sympy 各十二项，划分 18 开发、9 回归、9 最终测试。任务选择依据环境和参考解预检，不读取 Agent 成绩。公共任务训练污染风险必须写入报告。

回归集六配置各九项一次，共 54 次：固定 mini-swe-agent、自研基础单 Agent、完整单 Agent、独立并行、固定协作、自适应委派。外部基线需要固定版本并说明包装差异；本轮没有伪造这个外部系统的执行结果。

策略冻结后，最终九项用完整单 Agent 与选定协作策略各运行三次，再做 54 次。经验使用冻结快照；新候选经验不会自动影响其他运行。开发集用于检索、压缩、经验和委托验收消融，不把开发反馈用于最终集择优。
